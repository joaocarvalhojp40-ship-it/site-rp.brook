# Código de Conduta

Queremos um espaço respeitoso para todas as pessoas que participam deste projeto
(issues, Pull Requests e discussões).

## O que esperamos

- Tratar todos com respeito, mesmo em discordâncias.
- Dar e receber críticas de forma construtiva.
- Focar no que é melhor para o projeto.

## O que não é aceito

- Ofensas, assédio, discriminação ou ameaças.
- Spam, propaganda ou divulgação não solicitada.
- Publicar informações pessoais de outras pessoas.
- Tentar contornar as proteções do repositório (por exemplo, remover a assinatura do autor).

## Aplicação

O autor pode editar ou remover comentários, fechar issues e Pull Requests, e bloquear
quem descumprir estas regras. Para denunciar um comportamento, use o botão
**Report** do GitHub ou escreva para **joaocarvalhojp40@gmail.com**.
