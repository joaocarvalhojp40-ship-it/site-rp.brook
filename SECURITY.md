# Política de Segurança

## Como reportar uma vulnerabilidade

**Não abra uma issue pública** para falhas de segurança.

Use o relato privado do GitHub: na aba **Security** do repositório, clique em
**Report a vulnerability**. Descreva o problema, os passos para reproduzir e o impacto.

Se preferir, envie um e-mail para **joaocarvalhojp40@gmail.com** com o assunto "Segurança - CNV".

## O que esperar

- Retorno inicial em alguns dias.
- Correção publicada assim que possível, com crédito a quem reportou (se desejar).

## Escopo

- Falhas no código deste repositório, incluindo os Security Headers do `next.config.js`.
- Dependências com vulnerabilidades conhecidas.

Fora do escopo: problemas nos serviços de terceiros usados na hospedagem (Vercel, GitHub, Discord).
